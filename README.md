## スキル（道具）

`skills/` と `agents/` に、中道さんが普段使っている道具がそのまま入っています。図解・グリル・点検の3本です。

**渡すのは、中身を読んで書き換えてもらうためです。** 中身はプログラムではなく日本語の手順書なので、開けば全部読めます。**そのままでは動かないところもわざと残してあります。** 入れ方と、どこが動かないかは [04_スキルを入れる.md](04_スキルを入れる.md) にあります。

## 使い方

**そのとおりに進めて、詰まったら止めて連絡してください。** 全部を1人で解決しなくて大丈夫です。

手順の中で分からない言葉が出てきたら、**Claude Code にそのまま聞いてください。** 授業でずっとやってきたやり方と同じです。

```
（分からなかった文をそのまま貼る）
これはどういう意味ですか。
```

## エラーが出たら

**文章を全部コピーして Claude Code に貼る。** そのうえで「これはどういう意味ですか。どう直せばいいですか」と聞く。

**一部だけ切り取らない。** 全部貼るのが早道です。

---

道具は完成品のまま渡してあります。**使って、気に入らないところを自分で書き換える。** それが10回でやることです。

**書き換えて壊れても大丈夫です。** ここから取り直せます。
