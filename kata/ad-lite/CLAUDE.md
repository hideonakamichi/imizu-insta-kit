# 広告クリエイティブ Lite（競合の空きを見つけてバナーとLPを作る）

競合の広告コピーを手がかりに、まだ誰も言っていない訴求（空きポジ）を見つけ、
その訴求でバナーとLPのセクション画像を作る。**投稿・公開は人が手で行う。**

## 入口

| 頼まれたこと | 使うもの |
|---|---|
| 「広告クリエイティブを作って」「空きポジを分析してバナーとLPを作って」 | `orchestrator` エージェントに任せる |
| `competitors.md` を埋めたあとの変換 | `collect-toolkit` スキル（`orchestrator` が直接実行してよい） |

## コマンドの実行

- Python は Windows `py` ／ Mac `python3`
- **Bash ツール**で、`.claude/skills/.../scripts/...` の相対パスのまま実行する

## このキットに無いもの

- **Scrape（自動収集）が無い。** 競合広告は `data/<プロジェクト>/competitors.md` に人が手で書き写す
- **Publish（自動公開）が無い。** バナー・LP画像がそろったら終わり。公開は `addons/` にある

外した機能（自動収集・Vercel自動公開）は `addons/` にある。本体からは使わない。
