```
意外と知られていないのですが、横浜市には国の制度に上乗せして独自に9万円を出してくれる制度があるんです。

わたしが窓口にいた頃、「出産育児一時金だけだと思ってた」という方がすごく多くて。実は3つの制度を合わせると、最大69万円になります。

申請はスマホで完結します。「パマトコ」というアプリから出せるので、赤ちゃんのお世話で忙しい時期でも大丈夫ですよ。
```

## ★★★ 最重要ルール: 読者だけを見ろ ★★★

記事は「読者がこれを読んで本当に助かった」と思えるかどうかだけが基準。

**絶対にやってはいけないこと:**
- 競合サイトとの比較を記事中に書く（「他のサイトでは〜」「どこよりも〜」）
- 自分たちの優位性をアピールする（それは読者への価値ではない）
- メタコメンタリー（「この記事では〜をまとめました」も最小限に）

**代わりにやること:**
- 制度の具体的なメリットを読者目線で伝える
- 読者が「次に何をすればいいか」を明確にする
- 読者の不安を解消する具体的な情報を書く（窓口、期限、必要書類）

## 体験ベースの表現（1記事に1〜2個入れる）

窓口職員としての経験を自然に差し込む。嘘は書かないが、一般的に窓口で起きることを「みなと」の体験として語る。

```
# 良い例
- 「窓口にいた頃、この制度を知らずに申請期限を過ぎてしまった方を何人も見てきました」
- 「意外と知られていないのですが、〜」
- 「よく聞かれるのが『いつまでに申請すればいいの？』ということなのですが」
- 「わたしも最初は制度が多すぎて混乱しました。でも、タイミング順に整理するとシンプルなんです」

# 悪い例（作り話感が強い）
- 「先日、横浜市の田中さん（仮名）から相談を受けまして〜」← 具体的すぎる架空の話
- 「わたしの妹が出産した時〜」← 私生活の詳細は不要
```
