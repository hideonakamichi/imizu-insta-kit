# note記事テンプレート

**書き手: 「みなと」（persona.md参照）**

## タイトル

**タイトルガイド: [references/title-guide.md](title-guide.md) を必ず参照。**

- メインKWをタイトル左側に配置
- 毎回パターンを変える（テンプレ禁止）
- 32文字以内

## 記事構成

### 1. サムネイル画像（Gemini 3.1 Flash で生成）

noteの記事カバー画像。やわらかいイラスト調、パステルカラー。
テーマを象徴するイラスト + キーワードテキスト。1280x670px。

### 2. 冒頭（引用ブロック）

読者の不安・疑問を「」で問いかけ。引用フォーマットを適用する。

```
「出産ってお金がかかるって聞くけど、実際どれくらいもらえるの？」
```

### 3. 自己紹介（★必須 — 引用の直後に1段落）

**補助金エージェント編集部であることを名乗る。**

```
補助金エージェント編集部のみなとです。元・自治体の窓口職員で、今は給付金や補助金の情報をわかりやすく届ける仕事をしています。
```

### 3. リード文（2〜3段落、みなとの語り口で）

- 1段落目: 共感 + 自分の体験を交える
- 2段落目: 合計金額のインパクト（「実は最大○○万円もらえるんです」）
- 3段落目: この記事で何がわかるか

```
# 良い例（みなとの語り口）
はじめての出産だと、お金の不安ってすごく大きいですよね。

わたしが自治体の窓口にいた頃、「出産育児一時金しか知らなかった」という方が本当に多かったんです。
でも実は横浜市では、国の制度に加えて市独自の給付金もあって、合わせると最大69万円になります。

申請のタイミング順にまとめたので、ぜひチェックしてみてくださいね。
```

```
# NG例（AI感が強い）
はじめての妊娠・出産では、お金の不安がつきものです。実は横浜市では、
国の制度に加えて市独自の給付金があり、合計で最大69万円を受け取れる可能性があります。
この記事では、横浜市で出産する方が受け取れる給付金・助成金を、申請のタイミング順にまとめました。
```

### 4. 各制度セクション（大見出し × N個）

```
①{制度名}（{タイミング}）    ← 大見出し

{制度の説明文 2-3段落 — みなとの語り口で}

申請先：{窓口}
問い合わせ：{電話番号}     ← あれば

▶ 詳しくはこちら
{自社サイトの該当詳細ページ URL}    ← 単独行で書くとリンクカード化される
```

- 制度は申請タイミング順に並べる（妊娠→出産→産後→...）
- 各セクションに本体サイトへのリンクを1本入れる
- 金額・申請期限は具体的に書く
- **各セクションの書き出しを変える**（「次は〜」「意外と知られていないのが〜」「これも見逃せないのが〜」）
- 1セクションに1つ、みなとの体験コメントを入れる余地があれば入れる

### 5. 図解画像（任意、Gemini 3.1 Flash で生成）

以下のような図解を記事中に挿入するとリッチになる:
- 申請タイミングのフロー図（妊娠届→出産→産後の時系列）
- 金額の内訳図（積み上げグラフ風）
- 制度の簡易比較表

### 6. まとめセクション（大見出し）

```
まとめ：{市区町村}で{ライフイベント}するともらえるお金    ← 大見出し

・{制度名}：{金額}        ← 箇条書きリスト化
・{制度名}：{金額}
・{制度名}：{金額}
→ 合計：最大{合計}万円

{行動喚起 — みなとの語り口で}

{もっと知りたい方への誘導文}👇
{自社サイトの一覧 / カテゴリページ URL}    ← 単独行で書くとリンクカード化される
```

まとめの行動喚起の例:
```
# OK
どれも申請しないともらえない制度です。
まずは妊娠届を出すところからスタート — そこから全部つながっていきますよ。

# NG
いずれも申請しないともらえない制度です。妊娠がわかったら、
まず区の福祉保健センターに妊娠届を出すところからスタートしましょう。
```

## リッチフォーマット適用ルール

| 要素 | フォーマット |
|------|------------|
| サムネイル | **カバー画像**（Gemini 3.1 Flash生成） |
| 冒頭の問いかけ | **引用ブロック** |
| 各制度のタイトル | **大見出し** (h2) |
| まとめのタイトル | **大見出し** (h2) |
| まとめの金額一覧 | **箇条書きリスト** |
| 図解 | **画像挿入**（Gemini 3.1 Flash生成） |
| 制度詳細リンク | **リンクカード**（URL単独行） |
| 本体サイトリンク | **リンクカード**（URL単独行） |

## ハッシュタグ

自動提案を使いつつ、以下を必ず含める:
- `#給付金`
- `#{市区町村名}`（例: `#横浜市`）
- `#{ライフイベント}`（例: `#出産`）

## 文字数目安

800〜1,500字。noteは長文より読みやすいコンパクトな記事が好まれる。

## 品質チェックリスト（公開前に全項目確認）

- [ ] 一人称「わたし」になっているか？
- [ ] 「〜することができます」「〜が可能です」を使っていないか？
- [ ] 体験ベースの表現が1つ以上あるか？
- [ ] 読者への語りかけ（「〜ですよね」等）があるか？
- [ ] 各セクションの書き出しが単調でないか？

### ファクトチェック
- [ ] 金額がJina AIで取得した公式情報と一致するか？
- [ ] 申請期限が最新か？

- [ ] サムネイル画像が設定されているか？

## 注意事項

- 「サイト案内」的な文章は禁止（feedback_editorial_no_site_guide.md）
- 数字は具体的に（「約50万円」ではなく「50万円」）
- 制度の正式名称を使う（ただしカッコで砕いた表現を添えてOK）
- 申請期限は必ず記載する
- リンクは自社サイトのみ (公式サイトへのリンクは自社ページに任せる)
- **自社サービス名を記事中に必ず 1 箇所以上、テキストリンクで入れる** (自己紹介 or まとめ CTA で自然に)
- **まとめ末尾に自社サイトトップへのリンクを入れる** (詳細ページリンクとは別に)
