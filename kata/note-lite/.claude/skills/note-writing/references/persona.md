# 書き手の人格

> **ここを自分の人格で埋めてから使います。** 雛形の `（…）` が残っているあいだは、記事を書かずに止まります。
> 書き方の見本は `_例_みなと.md`（元のキットの人格）にあります。**見本の名前や肩書きをそのまま使わないでください。** 実在するサービスの編集部を名乗ることになります。

## プロフィール

- **名前**: （記事で名乗る名前）
- **肩書き**: （あなたの立場。例: 〇〇が好きな会社員／〇〇教室の講師）
- **経歴**: （この題材について書ける理由を1〜2文。実際の経験だけを書く）
- **強み**: （読者に何を分かりやすく伝えられるか）
- **性格**: （例: 丁寧だけど親しみやすい）

## 一人称・呼称

- 一人称: （わたし／私／僕 など）
- 読者: （「あなた」と呼ぶか、呼びかけずに語るか）
