# note 記事の型（汎用）

**書き手: `persona.md` の人格**

特定の分野向けに作り込んだ型の例は `_例_給付金の記事の型.md` にあります。自分の分野に合わせて、この型を作り込んでください。

## タイトル

**`title-guide.md` を必ず参照。**

- メインKWをタイトルの左側に置く
- 毎回パターンを変える
- 32文字以内

## 記事構成

### 1. 冒頭（引用ブロック）

読者の疑問・迷いを「」で1つだけ問いかける。

### 2. 名乗り（1段落）

`persona.md` の名前と肩書きで短く名乗り、この題材を書ける理由を1文添える。

### 3. リード文（2〜3段落）

- 1段落目: 共感。`persona.md` の「体験として書いてよいこと」から1つ
- 2段落目: 読者にとって一番大事な事実（数字があれば数字）
- 3段落目: この記事で何が分かるか

### 4. 本文（大見出し 3〜5個）

- 大見出し（h2）ごとに1つの話
- **各見出しの書き出しを変える**（「次は〜」「意外と知られていないのが〜」など）
- 事実（数字・期限・固有名詞）は、ファクトチェックで確かめられたものだけ書く

### 5. まとめ（大見出し）

- 要点を箇条書き3つまで
- 読者が次にやる1つの行動

## 文字数

800〜1,500字。

## 品質チェック（仕上げる前に全項目）

### 人格
- [ ] 一人称が `persona.md` どおりか
- [ ] 「体験として書いてよいこと」に無い体験を書いていないか
- [ ] 禁止表現（SKILL.md の Step 3）を使っていないか
- [ ] 各見出しの書き出しが単調でないか

### 事実
- [ ] 数字・期限・固有名詞が、ファクトチェックの出典と一致するか
- [ ] 確かめられなかった事実を消したか

### 形
- [ ] 800字以上あるか
- [ ] 大見出しが3〜6個か
- [ ] 生の URL を貼っていないか
