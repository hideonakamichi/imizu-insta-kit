# 投稿テーマキュー

note配信エージェント (`note-publisher`) はこのファイルを読んで、上から順に **未投稿 (`- [ ]`)** のテーマを 1 つ選んで記事化する。
完了したらチェック (`- [x]`) を入れて、投稿日と URL を追記する。

## 書き方

```markdown
- [ ] **テーマ名** — メインKW: `xxx` / サブKW: `yyy`, `zzz`
  - 切り口: 一言メモ
  - 想定読者: 主婦 / 学生 / フリーランス etc
  - 想定文字数: 1200
  - 参考URL (任意): https://...
```

完了後はこの形式に書き換える:

```markdown
- [x] **テーマ名** — 2026-05-06 / https://note.com/xxx/n/nyyyyyy
```

## キュー (上から順に処理される)

- [ ] **(サンプル) 在宅でできる副業の始め方** — メインKW: `在宅 副業 初心者` / サブKW: `在宅ワーク 主婦`, `副業 月3万`
  - 切り口: 月3万を目標に、未経験から始められる現実的な選択肢を比較
  - 想定読者: 30 代の主婦 / 育休中の方
  - 想定文字数: 1200
