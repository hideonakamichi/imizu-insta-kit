# 画像スタイルガイド（Gemini 3.1 Flash）

## APIモデル名

**`gemini-3.1-flash-image-preview`**（v1beta API）

他のモデル名は使わない。`gemini-2.5-flash` や `gemini-2.0-flash` は画像生成非対応。

## API呼び出し

```bash
curl -s "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-image-preview:generateContent?key=${GEMINI_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts": [{"text": "プロンプト"}]}],
    "generationConfig": {
      "responseModalities": ["TEXT", "IMAGE"]
    }
  }'
```

レスポンスの `candidates[0].content.parts` から `inlineData.data`（base64）を取り出してデコード。

## 保存先

`data/note-images/{city_slug}-{theme}-{type}.png`

例: `yokohama-birth-thumbnail.png`, `yokohama-birth-breakdown.png`

## サムネイル画像のトンマナ（★実績ベース — この指定で高品質画像が生成された★）

### カラーパレット
- **メインカラー**: ソフトピンク（#F8C8D4）、ミントグリーン（#B8E6D0）
- **サブカラー**: クリーム色（#FFF5E1）、薄い水色（#D4EAF7）
- **背景**: パステルカラーの円形パターン（ポルカドット風）
- **テキスト色**: 暖かみのあるオレンジ〜ブラウン系

### スタイル
- **イラスト調**（写真風は絶対NG）
- やわらかい線画、手描き感のあるタッチ
- ライフスタイルマガジンの表紙のような清潔感
- 人物は2頭身〜3頭身のかわいいイラスト

### 構成要素
- テーマを象徴するイラスト（人物+テーマアイテム）
- **大きな日本語テキスト**（テーマのキーワード、2〜3行）
- **サブテキスト**（都市名+補足）
- 周りに関連する小さなアイテムが舞っている（お金、書類、桜など）

### サイズ
- **16:9の横長**（noteの推奨カバー画像サイズ: 1280x670px）

### 実績プロンプト（横浜市・出産テーマ）

```
日本語のブログ記事のサムネイル画像を生成してください。横長（16:9）のアスペクト比で。
テーマは「横浜市で出産したらもらえるお金」です。
やわらかいパステルカラー（ピンク、ミントグリーン、クリーム色）を使い、
赤ちゃんを抱くお母さんのかわいいイラストと、周りにお金（紙幣やコイン）が舞っている様子を描いてください。
大きな日本語テキスト「出産でもらえるお金」を入れてください。
イラスト調で、写真風にしないでください。
```

### テーマ別バリエーション

| テーマ | 人物 | アイテム | テキスト |
|--------|------|---------|---------|
| 出産 | 母+赤ちゃん | 紙幣、コイン、桜 | 「出産でもらえるお金」 |
| 子育て | 親子（幼児） | おもちゃ、絵本、コイン | 「子育てでもらえるお金」 |
| 離婚 | 親+子ども | 書類、紙幣、家 | 「ひとり親の給付金」 |
| 失業 | スーツの人 | 書類、紙幣、就職情報誌 | 「失業したらもらえるお金」 |
| 住宅 | 家族+家 | 家、鍵、紙幣 | 「住宅の補助金」 |

## 図解画像のトンマナ

### スタイル
- **インフォグラフィック調**
- 同じパステルカラーパレットを使用（サムネと統一感）
- シンプルで情報量は絞る（3〜4項目まで）
- 日本語テキストは大きく、読みやすく

### 構成パターン

#### パターン1: 金額内訳図（最も汎用的）
制度を左から右に並べ、金額を大きく表示。右端に合計。

```
実績プロンプト:
日本語のインフォグラフィック画像を生成してください。横長（16:9）のアスペクト比で。
横浜市で出産した場合にもらえるお金の内訳図です。
3つの制度を左から右に並べた積み上げ風の図で：
1つ目「出産・子育て応援給付金 10万円」（ピンク）、
2つ目「出産育児一時金 50万円」（ミントグリーン）、
3つ目「横浜市独自 出産費用助成金 最大9万円」（クリーム色）。
右端に合計「最大69万円」を大きく表示。
やわらかいパステルカラーで、図解イラスト風。写真風にしないこと。シンプルでわかりやすいデザイン。
```

#### パターン2: タイムラインフロー図
申請タイミングを時系列で表示。妊娠→出産→産後。

#### パターン3: チェックリスト図
対象者・必要書類をリスト形式で。

## 品質チェック（画像生成後に必ず確認）

1. **テキストの読みやすさ**: 日本語テキストが崩れていないか（Geminiは日本語テキスト生成で稀に崩れる）
2. **金額の正確性**: 図解中の金額が記事と一致しているか
3. **カラーの統一感**: サムネと図解で同じパステルパレットが使われているか
4. **人物の品質**: 顔や手が不自然に崩れていないか
5. **アスペクト比**: 16:9の横長になっているか

問題があれば再生成する。プロンプトに「前回生成した画像の○○を修正して」とは言わず、プロンプトを調整して最初から生成し直す。
