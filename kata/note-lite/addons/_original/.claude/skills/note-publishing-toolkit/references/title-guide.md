# タイトル作成ガイド

## 基本ルール

1. **メインKWはタイトルの左側（先頭〜15文字以内）に入れる**
2. **毎回パターンを変える** — テンプレ化しない。人間が書いたバリエーションで
3. **32文字以内** — noteの一覧表示で切れないように
4. **都市名は必ず入れる** — ただし位置は柔軟に（末尾【】でもOK、文中でもOK）

## テンプレ化NGの理由

以下のように毎回同じ構造だと、AIが書いた感がバレる:
```
❌ 出産したらもらえるお金まとめ【横浜市版・2026年最新】
❌ 子育てでもらえるお金まとめ【名古屋市版・2026年最新】
❌ 離婚後にもらえるお金まとめ【大阪市版・2026年最新】
```

## 良いタイトル例（バリエーション）

### 出産テーマ
- 「出産でもらえるお金、横浜市だと最大69万円って知ってた？」
- 「出産費用が不安なあなたへ｜横浜市の給付金3つを全解説」
- 「出産したら絶対申請して。横浜市で使える給付金まとめ」
- 「横浜市で出産するといくらもらえる？制度を全部調べた」

### 子育てテーマ
- 「児童手当だけじゃない！名古屋市の子育て給付金まとめ」
- 「子育て世帯が見落としがちな給付金5選｜大阪市版」
- 「名古屋市の子育て支援、実はこんなにあった」

### ひとり親テーマ
- 「離婚後に使える給付金、全部まとめた｜福岡市版」
- 「ひとり親家庭の支援制度、申請しないと損する3つ」
- 「母子家庭の給付金ガイド｜札幌市で使える制度一覧」

### 住宅テーマ
- 「引っ越し補助金、意外と出る自治体が多い｜東京23区」
- 「家賃補助がある自治体を調べてみた｜横浜市の場合」

## パターン分類

| パターン | 構造 | 例 |
|---------|------|-----|
| 驚き型 | 「{KW}、{都市名}だと{数字}って知ってた？」 | 出産でもらえるお金、横浜市だと最大69万円って知ってた？ |
| 命令型 | 「{KW}したら絶対申請して。{都市名}の〜」 | 出産したら絶対申請して。横浜市で使える給付金まとめ |
| 疑問型 | 「{都市名}で{KW}するといくら？全部調べた」 | 横浜市で出産するといくらもらえる？制度を全部調べた |
| 否定型 | 「{既知のもの}だけじゃない！{都市名}の〜」 | 児童手当だけじゃない！名古屋市の子育て給付金まとめ |
| 発見型 | 「{都市名}の{テーマ}、実はこんなにあった」 | 名古屋市の子育て支援、実はこんなにあった |
| 警告型 | 「申請しないと損する{テーマ}N選」 | ひとり親家庭の支援制度、申請しないと損する3つ |

**同じパターンを連続で使わない。** 最低3パターンはローテーションすること。
直近3記事のタイトルパターンをログで確認し、別のパターンを選ぶ。

## サブKWの見出しへの配置

メインKWはタイトルに入れるが、サブKWは見出し（h2）や本文に自然に散りばめる。

例（メインKW: 出産 もらえるお金）:
- h2: 「①妊婦のための支援給付（出産前に申請）」← 「出産前 申請」がサブKW
- 本文: 「出産費用の負担を減らせる制度です」← 「出産費用」がサブKW
- h2: 「まとめ：横浜市の出産給付金は合計69万円」← 「出産 給付金」がサブKW
