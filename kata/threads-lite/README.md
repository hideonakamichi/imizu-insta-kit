# Threads Lite（文体をまねて、毎日1本）

自分のテーマか、自分で書いた文章を渡すと、その**文体をまねた Threads の投稿を7日分**ストックします。
毎日「今日の1本」をファイルに書き出すので、**自分で Threads アプリに貼って投稿**します。

```
テーマか自分の文章を渡す（初回だけ）
   ↓ 文体・主張・読者を読み取る → 人が確認して OK
7日分の本文をストック
   ↓ 毎日
今日の1本を output/today.txt に書き出す → 自分で投稿 → 「投稿した」と記録
   ↓ ストックが減ったら
「ネタを補充して」
```

- 動く OS … Windows・Mac（Node.js が要ります。レッスン4で入れたもの）
- 外部サービスのアカウントとキー … 要りません
- 費用 … Claude の利用量だけ（本文を書くとき）。今日の1本を出す・記録する処理は AI を使いません

元は、Threads API で毎日自動投稿する講義用テンプレートです。自動投稿・反応の取得・分析・定期実行は
`addons/threads-api/` に外してあります。

## はじめかた

1. このフォルダを VS Code で開く。「このフォルダを信頼しますか」と聞かれたら承認する
2. Claude Code にテーマか文章を渡す

   ```
   テーマは（あなたのテーマ）です。次の文章の文体で投稿を作ってください。
   （ここに自分の文章を貼る。ブログや note の記事など）
   ```

   note の URL を渡しても読みに行きます。文章が多いほど、文体の読み取りが正確になります

3. 読み取った文体と主張が見せられるので、ずれていれば直してもらう。よければ「OK」と伝える
4. 毎日、Claude Code に「今日の1本を出して」と頼む。`output/today.txt` の中身を Threads アプリに貼って投稿する
5. 投稿したら「投稿した」と伝える。**伝えないと、明日も同じ本文が出ます**

「今日の1本」と記録は、ターミナルで直接打っても同じです（AI を使わないので利用量はかかりません）。

```bash
npm run threads:today     # 今日の1本を output/today.txt に書き出す
npm run threads:posted    # 投稿したことを記録する
```

## 止まる仕組み

| 止まるとき | 理由 |
|---|---|
| 今日すでに記録がある | 1日1本まで |
| 同じ本文をもう投稿している | 重複投稿を防ぐ |
| まだ投稿していない下書きが無い | 「ネタを補充して」と頼む合図 |
| 本文が500文字を超えている | Threads の上限 |

## 自分用に直す場所

| 変えたいもの | 場所 |
|---|---|
| テーマ・文体・主張・避ける言葉 | `data/topic-profile.json`（初回の取り込みで作られる） |
| 7日分の切り口の種類 | `.claude/skills/threads-topic-intake/SKILL.md` の「切り口」 |
| 本文を書くときの決まり | 同上の「セルフチェック」 |

## ディレクトリ構成

```
CLAUDE.md                共通ルール（Claude Code が毎回読む）
.claude/skills/          取り込み・下書き・今日の1本・全体の段取り
.claude/agents/          司令塔・下書きのレビュー役
scripts/                 下書きの変換・今日の1本・記録（AI を使わない決まった処理）
data/                    発信の核・ストック・下書き・投稿の記録
output/today.txt         今日の1本（毎回上書き）
addons/threads-api/      外した機能（自動投稿・反応の取得・分析・定期実行）
addons/_original/        元のテンプレートの文書
```

## 利用について

Threads の利用規約は各自で確認してください。投稿の内容とその影響は、投稿した人の責任になります。
