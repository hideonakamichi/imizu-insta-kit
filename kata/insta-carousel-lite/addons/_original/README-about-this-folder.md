# _original — フル版の元の文書

Lite 版を作る前の、フル版（insta-autopost-kit）の文書と設定をそのまま置いています。
追加パックを足すとき、Lite 版で削った理由を確かめるとき、教材で「フル版から何を削ったか」を見せるときに使います。

| ファイル | 中身 |
|---|---|
| `README.md` | フル版の説明（運用の実績と費用、つまずき） |
| `CLAUDE-full.md` | フル版の共通ルール（ファイル名を変えてある。`CLAUDE.md` のままだと Claude Code がルールとして読み込むため）（無人実行の制約を含む） |
| `SETUP-GUIDE.md` | Meta・R2・Discord・Grok・Fish Audio の設定手順 |
| `loop-limits.yaml` | リール・投稿を含むやり直し回数の上限 |
| `settings.json` | 全パイプラインぶんの許可リスト |
| `requirements.txt` | 全パイプラインぶんの依存 |
| `evaluator-full.md` | リールの基準を含む、フル版の評価役 |
