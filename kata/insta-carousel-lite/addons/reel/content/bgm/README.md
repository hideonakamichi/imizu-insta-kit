# BGM音源について

リール動画の背景音楽をここに置きます（`.mp3`）。

**音源はこのキットに含まれていません**（ライセンスの都合）。リールを使う場合は、下の条件を満たす
`.mp3` を自分で1つ置いてください。無くてもリールは作れますが、**BGM なし（ナレーションと効果音だけ）**になります
（`narrate_and_mix.py` が警告を出して続行します）。

手元に音源が無ければ、Grok に短いBGMを作らせる方法もあります（例:「15秒の落ち着いたロービートの
インストゥルメンタルを作って」）。生成物の権利は xAI の利用規約に従います。

## 選ぶときの条件

- **商用利用が許諾されているもの**（Instagram投稿は商用利用にあたる場合があります）
- **帰属表示（クレジット表記）の要否を必ず確認する**。必要ならキャプションに入れること
- 落ち着いたインストゥルメンタル。ナレーションの邪魔をしないもの
- 1〜3分程度あれば十分（動画尺に合わせて自動でループ・カットされます）

Instagramの音楽ライブラリの楽曲は、APIから投稿する動画には使えません。
必ず音源ファイルとして用意してください。

## 音量について

`narrate_and_mix.py` がナレーションに対して十分小さい音量でミックスします。
（`mix_bgm.py` は旧スライド式パイプライン用のレガシースクリプト）
音量を調整したい場合は `.claude/skills/reel-production/SKILL.md` の該当ステップを参照してください。

## 複数置いた場合

実装（`narrate_and_mix.py`）は `reel_meta.json` の `bgm_file` で指定された音源を使い、
指定が無い・指定のファイルが見つからないときは**このディレクトリの先頭のmp3（ファイル名順）を固定で**使います。ランダム選曲はしません。
毎回同じBGMになりますが、これは意図的な設計です（ブランドサウンドとして定着させるため）。
曲を変えたいときは `bgm_file` で明示的に指定してください。
