# 固有名詞・誤認識補正辞書 (correction-dictionary)

`correct_srt.py` がこのファイルを読み込んで、Whisperの音声認識結果を一括補正する。
このアカウント固有の固有名詞（商品名・サービス名・繰り返し使う専門用語）が誤認識される
場合はここに追記していく。運用開始時点では空（プレースホルダのみ）。

## フォーマット

- **1行1ルール**: `OLD => NEW` の形式
- **コメント**: `#` で始まる行と空行は無視
- **適用順序**: 上から順に処理。長い表現を先に書く
- 行頭限定で削除・置換したい場合は `LEADING:OLD => NEW` の形式（`verbose-patterns.md` 側で使用）
