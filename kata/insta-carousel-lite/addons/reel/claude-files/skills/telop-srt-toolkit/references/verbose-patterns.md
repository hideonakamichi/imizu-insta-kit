# 冗長口語表現の削除リスト (verbose-patterns)

参照: myuuu-io/youtube .claude/skills/telop-srt-toolkit/references/verbose-patterns.md をそのまま流用
（日本語の一般的な冗長表現パターンのため、チャンネル固有ではなく汎用）。

`correct_srt.py` がこのファイルを読み込んで SRT 本文の冗長表現を一括削除/置換する。

## フォーマット

- **1行1ルール**：`OLD => NEW` の形式
- `NEW` 空文字は削除（`OLD => ` で削除）
- **コメント**：`#` で始まる行と空行は無視
- **適用順序**：上から順に処理。長い表現を先に書く

---

## 「というふうに」系（最頻出の冗長表現）

というふうに思います => と思います
というふうに思って => と思って
というふうに思っています => と思っています
というふうに => と

## 冒頭フィラー（行頭限定で削除する想定。correct_srt.py が --leading オプションで処理）

# 注意：以下は行頭限定マッチが必要。correct_srt.py が --leading オプションで処理
LEADING:はい今回 => 今回
LEADING:はいそれでは => それでは
LEADING:はい では => では
LEADING:はい、 =>
LEADING:えーっと =>
LEADING:えっと =>
LEADING:あー =>
LEADING:えー =>

## その他の冗長表現（必要に応じて追加）

# みたいな感じになっています => のようになっています
# っていうふうな感じで => のような感じで
# させていただいて => して
