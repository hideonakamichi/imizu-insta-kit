# 書体（Noto Sans JP）

スライドの文字は、このフォルダの2ファイルだけで描きます。OS に入っている書体を使わないので、
Windows でも Mac でも同じ見た目になります。

| ファイル | 使いどころ |
|---|---|
| `NotoSansJP-Black.otf` | 見出し・箇条書き（太い方） |
| `NotoSansJP-Bold.otf` | サブテキスト・ページ番号・誘導文 |
