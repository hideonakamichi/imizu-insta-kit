# Instagram カルーセル Lite（小さく始める版）

自分で書いた文章を置いておくと、その1節を根拠にして Instagram 用の図解カルーセル（3〜6枚）を作るキットです。
Claude Code に「カルーセル作って」と頼むと、ネタ選び・構成・描画・評価・キャプションまでを行い、
合格したものだけを投稿用フォルダにそろえます。**投稿は、自分でスマホから行います。**

```
自分の文章（content/sources/*.md）
   ↓ 見出し（##）ごとに切り分けてネタにする
ネタ選び → 構成 → 描画 → 評価 → キャプション → 評価
   ↓ 合格したときだけ                 ↓ 2回直しても不合格なら
投稿用フォルダ（01.png〜 と caption.txt）   作らずに止めて、理由を伝える
   ↓
自分でスマホから投稿
```

Windows と Mac のどちらでも動きます。

---

## フル版から何を削ったか

このキットは、自動投稿までを無人で行う「Instagram 自動投稿キット」を、費用と準備を小さくするために削ったものです。

| | フル版 | Lite 版 |
|---|---|---|
| 作るもの | カルーセル＋リール（動画）＋週次点検 | カルーセルだけ |
| 投稿 | Instagram の API で自動投稿 | 自分でスマホから |
| 起動 | Mac の launchd で決まった時刻に無人実行 | Claude Code に話しかける |
| 必要な外部サービス | Meta for Developers・Cloudflare R2・Discord・Grok・Fish Audio | なし |
| 動く OS | Mac | Windows・Mac |
| 費用 | Claude の利用量＋各サービス（月 $80〜100 相当） | Claude の利用量だけ |

削ったもののうち、自動投稿・リール・定期実行は `addons/` に「追加パック」として残してあります。
慣れてから足せます（ただし、まだ Mac 専用です）。

---

## 始める前に知っておいてほしいこと

**評価役（evaluator）が、かなり厳しく落とします。** 作ったものは毎回、評価専用の AI が合否を判定し、
不合格なら直してもう一度出します。2回で通らなければ、投稿用フォルダを作らずに止めます。
「変な投稿が出るくらいなら出さない」側に倒した設計です。フル版の実績では、カルーセルは6回中5回が合格しました。

**費用は1回ごとにかかり、止まった回にも同じだけかかります。** かかるのは Claude Code の利用量だけです。
サブスクリプションで使っている場合は、請求額ではなく利用枠の消費になります。
フル版のカルーセルは1回あたり平均 $4.1（API の定価換算）でした。Lite 版は投稿の手順がないぶん少し減る見込みですが、
まだ測っていません。モデルの選び方で上下します（`docs/SETUP-GUIDE.md` の「モデルの選び方」）。

**投稿の中身の責任は、投稿する人にあります。** 評価役は完全ではありません。投稿する前に、必ず自分の目で見てください。

## 必要なもの

- Windows または Mac
- [Claude Code](https://claude.com/claude-code)
- Python 3.10 以上

外部サービスのアカウントやキーは要りません。

---

## はじめかた

画面の操作まで含めた手順は `docs/SETUP-GUIDE.md` にあります。ここは全体の流れです。

1. **ライブラリを入れる。** このフォルダでターミナルを開いて実行します（Mac は `py` を `python3` に読み替えます）

   ```bash
   py -m pip install -r requirements.txt
   ```

2. **Claude Code でこのフォルダを開き、初期設定をする。**「このフォルダを信頼しますか」と聞かれたら承認します

   ```
   brand-setup スキルで設定して。発信したいのは〇〇で、売りたいのは△△
   ```

   対話で答えていくと、`config/brand.yaml`（誰に・何を・どんなトーンで）と、投稿の根拠になる文章の最初の数本ができます

3. **1本作る**

   ```
   カルーセル作って
   ```

   フル版では1本10〜20分かかっていました。終わると `output/<日付>_<テーマ>/post/` に `01.png`〜 と `caption.txt` がそろいます

4. **スマホから投稿する。** 画像を `01` から順に選び、`caption.txt` の中身を貼ります。
   投稿しなかったときは「これは没」と伝えると、そのネタが履歴から外れて、また選ばれるようになります

## ネタ元の文章について

投稿は、`content/sources/` に置いた Markdown の1節（`## 見出し` の単位）の紹介として作られます。
画面とキャプションに書かれる事実は、その節に書いてあることだけです。AI が自分の知識で話を足すと、評価役が不合格にします。

ですから、**ここに置く文章の質が、そのまま投稿の質になります。** 固有の数字・手順・理由・資料名が入っているほど、中身の濃い投稿になります。
置くものは、ブログや note の記事、よく聞かれる質問とその答え、講座の台本など、自分が内容に責任を持てる文章です。
書式は `content/sources/README.md` にあります。

同じ節は、ほかに選べる節があるかぎり14日間は再登場しません。週に投稿する数の2倍以上の節があると、繰り返しを避けられます。

## 設定を変えたいとき

| 変えたいもの | 場所 |
|---|---|
| 読者・トーン・誘導文・ハッシュタグ | `config/brand.yaml` |
| スライドの3色 | `config/brand.yaml` の `design.palette` |
| OS・Python の呼び方 | `config/runtime.yaml` の `os` / `python_command` |
| ネタ選び・キャプション・評価のモデル | `config/runtime.yaml` の `models` |
| 司令塔のモデル | Claude Code の `/model` |
| 評価の基準 | `.claude/agents/evaluator.md` |
| スライドの文字量の上限 | `.claude/skills/banner-production/references/carousel-spec.md` |
| スライドの見た目（文字の大きさ・余白） | `.claude/skills/banner-production/scripts/render_slides.py` の数値 |

見た目はプロンプトではなく、プログラム（Pillow）が数値どおりに描いています。見た目を変えたいときは、
`render_slides.py` の数値を直してください。

## ディレクトリ構成

```
config/brand.yaml        アカウントの人格（読者・トーン・オファー・色・ネタ元の設定）
config/runtime.yaml      動かす環境（OS）と、AI モデルの割り当て
config/loop-limits.yaml  やり直し回数の上限（緩めると、失敗したときに費用だけがかさむ）
content/sources/         ネタ元（自分の文章を Markdown で置く）
content/articles/        ネタ元から自動で切り出された、節ごとの根拠テキスト（手で編集しない）
content/themes.md        いまある紹介ネタの一覧（自動生成。眺める用）
.claude/skills/          carousel（入口）・banner-production（描画）・brand-setup（初期設定）・shared（共通スクリプト）
.claude/agents/          ネタ選び・キャプション・評価の各エージェント
assets/fonts/            スライドの書体（Noto Sans JP。OFL ライセンスで同梱）
docs/SETUP-GUIDE.md      Windows と Mac の手順・モデルの選び方・つまずきやすい点
docs/DESIGN.md           見た目の方針（余白・3色以内・1枚1メッセージ）
docs/overview.html       全体の図解（docs/icons/ のアイコンを使う。フォルダごと配る）
examples/                カルーセル構成の作例
output/                  生成物（1本ごとにフォルダが残る。post/ が投稿用）
logs/history.jsonl       作成履歴（ネタの重複を防ぐ）
addons/                  外した機能（自動投稿・リール・定期実行）と、フル版の元の文書
CLAUDE.md                共通ルール（Claude Code が毎回読む）
```
