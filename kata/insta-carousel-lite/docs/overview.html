フル版と Lite 版

フル版

  • API で自動投稿
  • カルーセル＋リール＋週次点検
  • Mac の launchd で無人実行

Lite 版

  • 人がスマホから投稿
  • カルーセルだけ
  • Claude Code に話しかけて起動
