# DESIGN.md — 発信物デザイン方針メモ

このファイルは、サムネ・図解・スライド・インフォグラフィックなど**視覚的な発信物の「見た目の基準（憲法）」**。
画像やスライドなど見た目に関わる成果物を作る・直すときは、まずこの方針に沿って提案・修正する。

- **対象**: AIアシスタント（毎回の制作・修正の物差しとして使う）
- **更新**: 方向性が変わったらここを直す。個別スキル（banner-production）より上位の方針として扱う
- **関係**: 「どんな見た目にするか」がこのファイル。「誰に何を発信するか」は `config/brand.yaml`。
  配色の実際の3色は `brand.yaml` の `design.palette` で指定する

---

## 0. このメモの使い方（強制度）

**原則従う＋逸脱は提案**。

- 基本は本メモの方針に沿って提案・修正する。
- 内容上、本メモから外した方が明確に良くなる場合は、**「なぜ外すか」を一言添えて別案を提示**してよい（黙って逸脱しない）。
- 迷ったらミニマル側に倒す（足すより削る）。

---

## 1. Mission（目指す見た目）

**世界観 = Minimal（ミニマル）。**

余白を活かし、要素を削ぎ落とした、上品で清潔な見た目。
読者が「要点を一目で掴み、続きを読みたくなる」こと。情報がスッと頭に入ることを最優先する。

- 装飾より**伝わりやすさ**。
- 盛るより**削る**。
- 1つの発信物（1枚の画像・1枚のスライド）= **1メッセージ**。

---

## 2. Style Foundations（見た目の基礎）

### 配色

- **抑えた配色**を基本とする。使う色は「ベース1 + 文字1 + アクセント1」の**3色以内**を目安にする。
- 背景は明るく落ち着いたトーン（白・オフホワイト・淡いグレー等）。アクセント色は**強調したい1点だけ**に使う。
- 高コントラストを保つ（薄い文字を薄い背景に置かない）。読めることが最優先。
- 多色・グラデーション過多・ネオン的な発色は避ける（Minimalの世界観から外れる）。

### タイポグラフィ（文字）

- **全要素を日本語で**（タイトル・ラベル・注釈・補足・ボトムバーまで）。英語のみの図解・サムネは作らない。
- 文字の強弱（サイズ・太さ）で**視覚階層**を作る。「一番言いたいこと」が一番大きく見えること。
- 書体は1〜2種類に絞る。読みやすいゴシック系を基本とする。

### 余白・レイアウト

- **余白を恐れない**。詰め込まず、要素の周りに息をする空間を残す。
- 整列をそろえる（左揃え基準など、軸を決めて崩さない）。
- 余白・間隔は一定のリズムで（バラバラの隙間を作らない）。

---

## 3. テキスト圧縮（サムネマスター8原則）

画像内のテキストは多すぎると読みにくい。以下で情報量を最適化する（既存 infographic-prompt スキル由来）。

1. **具体語に圧縮**: 長い表現を1〜2語へ（例「生の計算資源の量」→「計算資源」）
2. **構造化記号**: 矢印（→）・等式（=）・対比（vs）を活用
3. **冒頭に核心**: 最初の1〜2行で結論を出す
4. **数字を強調**: 数字は明確に見せる。ただし**数字単体でなく「その数字が何を意味するか」が分かる形**で出す
5. **タイトルは断定的に**: 疑問形を避け、言い切る
6. **吹き出しは核だけ**: 主語・修飾を削り、キーワードのみ
7. **引用・権威付けは最小限**: シンプル重視なら削る
8. **文脈説明は最小限**: シンプル重視なら削る

> 特に **No.4** はあなたが繰り返し求めている点：「数字を強調する」だけで終わらせず、**その数字の意味が伝わる**設計にする。

---

## 4. 脱AIデザイン

- いかにもAIが自動生成した感（不自然な装飾・意味のない3D・過剰なグラデ・テンプレ臭）を避ける。
- 意味のない飾りを置かない。すべての要素に「なぜそこにあるか」の理由を持たせる。
- 実在しない図表・グラフ・ロゴ風の飾りを生成させない（読者に誤情報として伝わるため）。

---

## 5. Tone（トーン）

- 上品・落ち着き・信頼感。（この1項目だけは、brand-setup が発信ジャンルに合う記述へ書き換える）
  （`config/brand.yaml` の `tone.voice` と矛盾しないようにすること）
- 煽りすぎない。誇張より事実と要点で惹きつける。
- アクセント色は1画面につき強調1点だけに使い、塗り面を広げない。

---

## 6. Rules — Do / Don't

**Do（やる）**
- ✓ 1発信物 = 1メッセージに絞る
- ✓ 言いたいことを一番大きく・目立たせる（視覚階層）
- ✓ 余白を残す／3色以内／高コントラスト
- ✓ 全テキスト日本語
- ✓ 数字は「意味」とセットで見せる

**Don't（やらない）**
- ✗ 要素・色・文字の詰め込み
- ✗ 低コントラスト（読みにくい配色）
- ✗ 英語のみの図解・サムネ
- ✗ 数字を意味なく並べるだけ
- ✗ 意味のない装飾・AI自動生成感

---

## 7. Quality Gates（出す前のセルフチェック）

成果物を出す前に、以下を満たすか確認する（満たさなければ直す）。

- [ ] パッと見て「一番言いたいこと」が分かるか
- [ ] 色は3色以内・高コントラストで読めるか
- [ ] 全テキストが日本語か
- [ ] 数字は「意味」が伝わる形か
- [ ] 余白は十分か（詰め込んでいないか）
- [ ] 削れる要素はもう無いか
