# 提案文の型（解説）

完成形の模範は [examples.md](examples.md)。手順・提出ルール → [SKILL.md](../SKILL.md)、[submission-rules.md](submission-rules.md)。対象 A〜D → [audience-types.md](audience-types.md)。

## 初めの4問 → 一発出し

```
1. 提案したい内容
2. 誰に出すか（＋ A〜D）
3. 何を知りたいか
4. 何を言い切るか
        ↓ 4問以外は聞かない
   提出用完成稿を1本（AI一発出し）→ そのまま提出
```

再実行するときは4問の材料を直して **最初から**。完成稿を Typing で直さない（ルール②）。

## 結論＝要約＋判断

提案文書の「結論」は、データの要約だけでなく「判断」が乗ったものを指す。

要約だけ（NG）— 意思決定者が「それで？」となる:

```
3クォーターの売り上げを分析しました。北米12%増、欧州5%減でした。
```

要約＋判断（OK）— 意思決定者が次の行動を取れる:

```
欧州の落ち込みは一時的です。来期、新製品を欧州に投入すれば全体で2桁成長に戻せます。
```

結論1行の型：[やること] ＋ [なぜ（4問にあれば）] ＋ [何をしてほしいか]

## 対話の流れ（例）

> ユーザー：提案で定例会議を減らしたい  
> AI（①済）：内容は定例会議の見直しですね。  
> AI（②）：誰に出しますか？ 推奨：直属部長（A）。  
> ユーザー：部長  
> AI（③）：部長が知りたいのは「どの会議か／何がよくなるか／自分は何をすればいいか」でよいですか？  
> ユーザー：OK  
> AI（④）：何を言い切りますか？ 例：報告定例3本を隔週にし、ご承認をお願いします。  
> ユーザー：それでOK。週7本・12時間が根拠  
> AI：**提出用完成稿を1本だけ出力**（下書き・グリル・段落修正ループなし）

## 上流を埋めないとどうなるか（Before）

**Before（4問が空っぽのまま一発出し）**

```
お疲れ様です。会議運営の効率化についてご提案がございます。
最近、会議時間の増加が生産性低下の要因として指摘されています。
つきましては、定例会議の頻度の見直しをご検討いただけますと幸いです。
```

丁寧だが、どの会議か・何がよくなるか・何をしてほしいかに答えていない。**4問を埋めてから一発出しする。**

## メンツを守る言い換え（NG / OK）

**NG（過去を否定）**

```
今の定例会議は無駄が多く非効率です。やめるべきです。
```

**OK（状況変化＋功績を立てる）**

```
定例会議は立ち上げ期に足並みを揃えるのに役立ってきました。
人数も増えて自律的に動ける今、形を変えるタイミングだと思います。
まず1ヶ月、報告は資料共有に切り替えて試させてください。
```
