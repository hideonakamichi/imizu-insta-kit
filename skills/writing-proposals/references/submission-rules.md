# 提出の2ルール（最優先）

正本は本ファイル。[SKILL.md](../SKILL.md) の他の手順より **常に優先** する。

## ルール① AIによる一発出し

提案文は **AI による一発出し** で作る。AI と何度もやり取りして **文章を磨き上げる** のではなく、スキルを用いたアウトプットを **そのまま提出物** に使う。

**このルールの対象外（許されるやり取り）:**

- 初めの **4問** への回答（[SKILL.md](../SKILL.md)「初めに聞く4問」）
- 4問のうち、起動時にユーザーが **すでに言っていた内容** の確認・整理

**禁止（ユーザー向け）:**

- 【下書き】を出してから一緒に直す
- 「ここをもう少し…」と **提案文そのもの** をチャット上で何度も修正する
- grill-me で下書きを1問ずつ詰めてから再出力する **ユーザー向けループ**

**AI 内部:** 一発出しの前に [output-quality.md](output-quality.md) と [examples.md](examples.md) を参照してよい。ユーザーには **完成稿1本だけ** 見せる。

## ルール② 手作業の文章修正は禁止

提出する提案文を、タイピングや音声入力で **手作業で書き換えない**。AI が出力したまま提出する。

**直したいとき:**

1. 提案スキルや AI に渡す **コンテキスト（4問の答え・前提）** を整理・修正する
2. **最初から** スキルを再実行する（一発出しを出し直す）

ユーザーによる Typing での部分修正・言い回し調整は **一切禁止**。

## 4問と一発出しの関係

```
起動 → 初めの4問（足りない分だけ）→ 内部ゲート → 提出用完成稿を1本だけ出力 → そのまま提出
                ↑                                    ↑
         ルール①の対象外                    ルール①②の提出物
```

再実行が必要なときは、4問の答えを直して **最初から**。完成稿の段落をチャットで直さない。
