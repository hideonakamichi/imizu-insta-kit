# 提案の対象（読者タイプ）

起動直後の **4問の②「誰に出すか」** で確定する。詳細 → [SKILL.md](../SKILL.md)。手順 → 本ファイルは読者別ルールのみ。

| ID | ラベル | いつ選ぶか |
|----|------------------|------------|
| **A** | 直属上長・部長（社内承認） | 制度変更・業務改善・ツール導入など、上司の承認が必要なとき **（推奨・デフォルト）** |
| **B** | 他部署の決裁者・経営会議 | 予算・人事・全社方針など、直属以外が決めるとき |
| **C** | 顧客・取引先（社外） | 社外への提案・見積・企画提示 |
| **D** | 同僚・チーム内（合意形成） | 承認より「やり方の合意」「巻き込み」が主目的のとき |

ユーザーが最初から「部長に」「取引先に」と言っていたら **4問②で再確認せず** 該当 ID をメモする。

## 確定後にメモする行

```
対象: A/B/C/D — [具体名があれば]
```

以降の対話・下書き・完成稿は、この ID のルールに従う。

---

## A — 直属上長・部長（社内承認）

**本スキルの主対象。** [examples.md](examples.md) の模範がそのまま使える。

| 項目 | ルール |
|------|--------|
| 相手の典型3問 | 何を変えるか／何がよくなるか／自分（上長）は何をすればいいか |
| 結論のお願い | 「ご承認をお願いします」など、承認依頼を1行で言い切る |
| 必須本文 | 工数・コスト、実行ステップ（開始時期）、効果の測り方。削減なら充当先。費用なら期間総額 |
| トーン | 簡潔・結論先行。メンツを守る言い換え（[writing-basics.md](writing-basics.md)） |
| 心の話 | 社内の具体場面を1〜2文（ユーザー発言のみ） |

---

## B — 他部署の決裁者・経営会議

A をベースに、**横断・全社インパクト**を足す。

| 項目 | ルール |
|------|--------|
| 相手の典型3問 | なぜ今か／他部署・全社への影響／決裁者が担うリスクと判断ポイント |
| 結論のお願い | 「ご判断をお願いします」「承認いただければ〜開始します」 |
| 追加必須 | 関係部署・既存方針との整合、スコープ（やらないこと）、試験運用・打ち切り条件 |
| トーン | A よりフォーマル。略語・内輪ネタは避ける |
| 模範 | 例2（採用ツール）のようにコスト対効果・比較表を厚めに |

---

## C — 顧客・取引先（社外）

**社内上長フォーマットをそのまま流用しない。** 挨拶・関係性・相手メリットを前面に。

| 項目 | ルール |
|------|--------|
| 相手の典型3問 | 自分に何のメリットか／リスクと信頼性／次に何をすればよいか |
| 結論のお願い | 「ご検討ください」「ご提案です」— 社内の「ご承認」は使わない |
| 必須本文 | 相手メリット、提供内容・条件、スケジュール、問い合わせ先または次のアクション |
| 任意 | 工数・社内コストは **相手向け本文に書かない**（ユーザー確認用に別メモ可） |
| 心の話 | 相手の課題・現場に寄せた事実。自社都合だけにしない |
| 注意 | 本スキルの `◎` 4段構成は使ってよいが、見出しは「ご提案の概要」等に言い換え可 |

社外専用の長文提案書・見積書テンプレが別にある場合は、そちらを優先し、本スキルは骨子・対話の補助とする。

---

## D — 同僚・チーム内（合意形成）

承認より **合意・巻き込み**。お願いの強さを弱める。

| 項目 | ルール |
|------|--------|
| 相手の典型3問 | 自分の負担は増えるか／全体として何が楽になるか／いつから試すか |
| 結論のお願い | 「試してみませんか」「この進め方で合意できますか」 |
| 必須本文 | 各自の役割分担、試験期間、合意の取り方（定例・チャット等） |
| 省略可 | 期間総額（社内経費が相手に関係ない場合）。ただし工数配分は書く |
| トーン | 対等。命令調・上から目線を避ける |

## 出力前ゲートへの追加（対象別）

| 対象 | ゲートで必ず確認 |
|------|------------------|
| A | 上長3問への回答、工数/コスト/測り方（該当時） |
| B | 上記 + 他部署影響・スコープ・打ち切り |
| C | 相手メリット・次アクション。社内承認語の混入なし |
| D | 役割分担・試験期間・合意の取り方。命令調なし |
