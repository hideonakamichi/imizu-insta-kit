# 図解 — 改行ルール

SSoT `starbucks-visual.md` §タイポグラフィ を補足。**HTML 生成前に必ず読む。**

## 原則

- **幅任せにしない** — 作者が `<br>` で文節を切る
- **1行の目安** — 全角 18〜22 字（スマホ）。PC では **短い文は改行しない**
- **句点「。」のあと** — 改行してよい
- **読点「、」の直後** — **改行しない**（意味の塊の途中で切らない）
- **3文以上** — 段落ではなく箇条書きへ

## PC とスマホ

| 画面 | ルール |
|------|--------|
| スマホ | h1 は 2〜3 行。長い文は `<br>` で分割 |
| PC（md+） | 1行に収まる文は `<br>` なし。無理に縦に積まない |

## 要素別

| 要素 | ルール |
|------|--------|
| h1 | 2〜3行。意味のまとまりで切る。アクセント1語のみ |
| サマリー見出し | 1〜2行。長いときだけ `<br>` |
| リード / 狙い | 1文1行。最大2行 |
| h2 / h3 | 改行しない |
| 本文 p | 最大2文。1文なら1行 |
| li | 1項目1行 |
| フロー図ラベル | 上：名詞 / 下：短い説明（2行まで） |

## NG 例

| NG | OK |
|----|-----|
| 「ここから先で、」で改行 | 1文で書く |
| 短い説明を3行に割る | 1〜2行 |
| カード内1文を `<br>` で2行 | 1行のまま |

## 提出物モードで使わない

- 「〇〇って、どういうこと？」の問いかけ段落
- 「ひとことで言うと ──」の導入行

## チェックリスト（HTML 前）

- [ ] 「、」の直後だけで切っていない
- [ ] PC で1行に収まるのに `<br>` が入っていない
- [ ] h1 が 4 行を超えていない
- [ ] 補助文は `text-*-muted`（`/70` は使わない）
