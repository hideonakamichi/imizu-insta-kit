# 図解 — 提出物モード完成稿

人のOKの前に、チャットへこの4つだけ出す。HTML は出さない。

**提出物モード** は Why / What / How / When の4層で網羅する。軽量モードの型選択（ロジックツリー等）は使わない。

ロール（内部）: 高度な論理と直感的な伝わりやすさ。社会人1年目でも背景・目的・具体策・スケジュールの全体像が一目で分かる。見出しに「初心者向け」は書かない。

## 前提

- 問0で **提出物** を選んだとき、または起動文に「提出物」「提案」「報告」とあるとき
- 材料（Why/What/How/When）が足りなければ、追加グリルで1問ずつ取る
- Mermaid は **subgraph 4つ** 必須。HTML は [html-submission.md](html-submission.md)

## 出力

### 1. 【図解の狙い】

読み手に **何を理解させ**、**どう動いてほしいか** を2〜3行。問3の一言と矛盾させない。

### 2. 【リード文】

問3の一言。1〜2行。体言止め可。

### 3. 【図解の構造化】

Why / What / How / When の4ブロック。各ブロック **3〜4要点**。体言止め・短いキーワード。Z視線（上→下）。

| ブロック | 内容 |
|----------|------|
| **Why** | 理由・背景（なぜやるのか） |
| **What** | ゴール（何を目指すのか・結論） |
| **How** | 具体策・アクション（どう実現するか） |
| **When** | スケジュール・ネクスト（いつまでに・誰が何を） |

### 4. 【Mermaid】

`flowchart TD` または `flowchart LR`。`subgraph` で4ブロックを分割。  
SSoT の `themeVariables` と `classDef` を必須。アクセントは **What の結論1点** または **When の最初の行動1点** にだけ。
