# 図解 — 固定質問（全文）

1ターン1問。形式は `grill-me/references/question-format.md`。A に `— 推奨`。

起動文に答えがあれば、その問は飛ばす。

---

## 0問目 — モード

**title:** `図解 0問目 — モード`

**prompt:**

```text
1. 決めたいこと: 軽量図解か提出物図解か。

推奨: 提出物 — 背景・目的・具体策・スケジュールまで網羅する。
```

| 枠 | label |
|----|--------|
| A | 提出物（Why/What/How/When） — 推奨 |
| B | 軽量（1メッセージ・型1つ） |
| C | 起動文の指定に従う |
| D | まだ決めない。テーマ確定後にもう一度聞く |

起動文に「提出物」「提案」「報告」があれば A。比較・概念だけなら B。

---

## 1問目 — 公開するか

**title:** `図解 1問目 — 公開の要否`

**prompt:**

```text
1. 決めたいこと: この図解を URL 公開するか。

推奨: 今は公開しない — 先にローカルで中身を確定できる。
```

| 枠 | label |
|----|--------|
| A | 公開しない（ローカルの HTML まで） — 推奨 |
| B | 公開する（人がOKした HTML を Surge する） |
| C | まだ決めない。4ステップのあとで聞く |
| D | 公開済みの URL を差し替える |

---

## 2問目 — パレット

**title:** `図解 2問目 — パレット`

**prompt:**

```text
1. 決めたいこと: 色はパターン1か2か。

推奨: パターン1（モダン・トラスト） — 未指定時の正本。青系で信頼感が出る。
```

| 枠 | label |
|----|--------|
| A | パターン1 モダン・トラスト（#F0F4F8 / #102A43 / #1890FF） — 推奨 |
| B | パターン2 サステナブル（#F2F5F3 / #1B4332 / #ECA72C） |
| C | 起動文の指定に従う（1でも2でもない指定はパターン1） |
| D | 2つを混ぜて使う（禁止。選んだらパターン1に戻す） |

D を選んだらパターン1で進み、混ぜないことを1行で伝える。

---

## 3問目 — 伝えたい一言

**title:** `図解 3問目 — 伝えたい一言`

**prompt:**

```text
1. 決めたいこと: この図解で言い切る結論を1文にする。

推奨: ユーザーがすでに書いた核を1文に縮める — 新しい主張を足さない。
```

| 枠 | label |
|----|--------|
| A | 起動文・貼った文の核を1文にする — 推奨 |
| B | 一言はチャットに書く |
| C | 対象読者向けに言い換える（中身は変えない） |
| D | まだ一言が無い。追加グリルで材料を取る |

---

## 人のOK（4ステップの直後）

**title:** `図解 — 完成稿の確認`

**prompt:**

```text
1. 決めたいこと: この4ステップで HTML を1本作るか。

推奨: この完成稿で HTML にする — 材料が揃っている。
```

| 枠 | label |
|----|--------|
| A | この完成稿で HTML を1本作る — 推奨 |
| B | 一言を直して、4ステップからやり直す |
| C | HTML は作らず、4ステップだけで終える |
| D | 型を変えて4ステップからやり直す |
