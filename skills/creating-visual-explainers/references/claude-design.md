## なぜ Claude Design か

公開されたキャンバス上で、本人が要素を選び、文字を直接編集し、元に戻せる。位置やサイズの微調整を言い直す往復が消え、**親が下書き、人が仕上げ**の分担になる。

## 従来 HTML（`base.html`）を使う場合

次のいずれかに当てはまるときだけ、`base.html` の従来手順に戻る。

| 条件 | 理由 |
|------|------|
| 印刷・PDF で配る | 額縁の印刷ボタンと1枚レイアウトが要る |
| Surge の URL で渡す必要がある | 既存の配布先・リンクを変えられない |
| 4月報告形式（SSoT §例外形式） | 額縁前提の型 |

迷ったら **Claude Design**。判断がつかなければ人に1問聞く。

## 作り方

### アートボードの割り方

| モード | アートボード |
|--------|--------------|
| 軽量 | **1枚。** 完成稿で選んだ型（ロジックツリー／マトリックス／フローチャート／ベン図）をそのまま1枚に |
| 提出物 | **4枚。** Why / What / How / When を1枚ずつ、左から右へ並べる |

1アートボード1メッセージ。Z視線（左上→右下）は各アートボードの中で守る。

### 色

**HEX 直値で書く。`tm1-*` / `tm2-*` の Tailwind クラス名は使わない。** キャンバス上で手編集したとき、独自に定義したクラス名は保たれる保証がないため。

選んだパレットの HEX を SSoT から引く。面積比はベース 70% / メイン 25% / アクセント 5%、カード面は `#FFFFFF`。1 と 2 を混ぜない。

### 文字

`typography.md` の改行ルールをそのまま適用する。幅任せの折り返しにしない。補助文は薄い文字色（SSoT の「補助の文字」）を HEX で指定する。

### 引き継ぐ禁止事項

絵文字、公式ロゴ・固有コピー、ヒーロー帯、全面塗り見出し、「初心者向け」ラベル、フッタークレジット、ネオ。旧 `sb.*` 色と ADS 青 `#3B82F6` も使わない。

## 保存と公開

下書きは案件の `output/{slug}.dc.html`（ワークスペース直下）。スキル内に保存しない。

公開は **固定4問の「公開するか」が要のときだけ。** Artifact として公開し、URL を報告する。否なら下書きのまま渡し、URL を作らない。

作り直しではなく**同じものを直す**ときは、既存の Artifact を更新する（新しい URL を作らない）。
