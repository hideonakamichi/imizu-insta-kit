# グリル設問フォーマット（正本）

毎回 **同じ型** で1問だけ出す。`grill-me` の Step 3 は **必ず** 本ファイルに従う。

**実行手段（止まらない）:**

| 優先 | 手段 | いつ |
|------|------|------|
| 1 | AskQuestion を同一ターンで1回 | そのツールがあるとき |
| 2 | チャットに同じ A〜E を出し、1問だけ待つ | AskQuestion が無い／失敗したとき |

手段2でも、title / prompt / A=推奨 / B→D 複雑 / E=その他 は変えない。表だけの設問は禁止。

## 選択肢の役割（固定）

| 枠 | 役割 | 作り方 |
|----|------|--------|
| **A** | **推奨** | 末尾に `— 推奨` を付ける |
| **B** | 代替案（いちばん単純） | A 以外の現実的な案のうち、**スコープ・運用が最も軽い**もの |
| **C** | 代替案（中間） | B より **1段複雑**（機能・人数・運用が増える） |
| **D** | 代替案（いちばん複雑） | C より **1段複雑**（B → C → D の順で複雑度が上がる） |
| **E** | **その他（チャットに書く）** | AskQuestion が自動付与する `Other…`。自由記述用。**D に「その他」を置かない** |

**複雑度の目安:** 実装量、運用負荷、人数、課金・権限、外部連携の数 — 論点に合わせて B→C→D を段階設計する。

---

## 見た目（固定）

```
┌─────────────────────────────────────────┐
│ グリル {N}問目 — {論点}          [title] │
├─────────────────────────────────────────┤
│ 1. 決めたいこと: …                       │
│                                         │
│ 推奨: … — …                             │
│                                         │
│  A  … — 推奨                            │
│  B  …（代替・単純）                      │
│  C  …（代替・中間）                      │
│  D  …（代替・複雑）                      │
│  E  Other…（その他・チャットに書く）     │
└─────────────────────────────────────────┘
```

## 鉄則

- **1ターン = 質問UI 1回 + 1問**（表や二重表示をチャットに書かない。AskQuestion が無ければチャット5択が質問UI）
- **推奨案を必ず先に書く**（理由は1文）
- **A = 推奨 / B・C・D = 代替（B→C→D で複雑） / E = その他**
- 自由記述だけの設問は **禁止**（E またはチャット追記で対応）

---

## 標準出力（AskQuestion・毎回これ）

| AskQuestion 項目 | 値（固定パターン） |
|------------------|-------------------|
| **title** | `グリル {N}問目 — {論点ラベル（5語以内）}` |
| **prompt** | 下記テンプレそのまま |
| **options[0].label** | `{推奨案} — 推奨` → **A** |
| **options[1].label** | `{代替・単純}` → **B** |
| **options[2].label** | `{代替・中間}` → **C** |
| **options[3].label** | `{代替・複雑}` → **D** |
| （自動） | `Other…` → **E**（その他・チャットに書く） |

### prompt テンプレ（コピペ用）

```text
1. 決めたいこと: {この1問で確定させる判断を1文}

推奨: {推奨案} — {理由を1文}
```

- **「1. 決めたいこと:」** で始める（prompt 内で太字マークダウンは使わない）
- **次行「推奨:」** — emダッシュ（—）で理由を続ける

### チャット側（任意・1行まで）

AskQuestion の前後に長文を書かない。表・「1〜4で答えて」は **出さない**。

---

## 回答を受けた直後（固定1行）

```markdown
**grill 記録:** {論点ラベル} = {ユーザーの回答を1行}
```

- **A〜D** を選んだ → ラベル内容をそのまま記録
- **E（Other…）** を選んだ → ユーザーが書いた内容を1行で記録

---

## 終了時（Step 4・固定）

```markdown
## グリル完了

### 決まったこと
- …

### 未決事項
- …（なければ「なし」）

### 次のステップ候補
- …
```

**AI方針**（A/B/C）が決まっていれば「決まったこと」に必ず含める → `_shared/ai-integration-check.md`（置き場所は `~/.claude/skills/_shared/`）

---

## 禁止フォーマット

| NG | 理由 |
|----|------|
| D を `その他（チャットで書く）` にする | E がその役割。D は代替案（複雑） |
| B/C/D の複雑度が逆転 | ユーザー指定ルール違反 |
| Markdown 表だけで選択肢を出さない | UI が毎回ぶれる |
| 推奨なし・質問UIなし | 形式ぶれ |
| AskQuestion が無いのにスキルを中断する | チャット A〜E で続ける |

---

## 模範（AskQuestion パラメータ）

**title:** `グリル 1問目 — 利用者と目的`

**prompt:**
```text
1. 決めたいこと: 誰が・何のためにこのアプリを使うか（成功の定義の前提）。

推奨: まず自分用の制作ツール — 用途と成功基準を決めやすく、MVPを小さく保てる。
```

**options（B→C→D で複雑度 UP）:**

| id | label | 複雑度 |
|----|-------|--------|
| a | 自分用（企画→動画まで個人で完結） — 推奨 | 推奨 |
| b | 社内・チーム向け（同一ワークフロー・共有のみ） | 低 |
| c | 不特定多数向けSaaS（アカウント・課金・運用あり） | 中 |
| d | エンタープライズ（SSO・監査ログ・複数部署テナント） | 高 |
| （E） | Other… | その他（チャット） |
